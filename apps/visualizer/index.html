A compiler backend,
not a prettier AST.

Traditional obfuscators rename variables and inject dead code. TSXobf is a full compiler pipeline: source to semantic IR to encrypted bytecode to a generated VM runtime.

01

TypeScript project analysis

Resolves imports, exports, scope rules, and typed symbols through the official TS Compiler API.

02

Register-based IR

Selected functions lower into a typed intermediate representation with explicit control flow, no hidden branches.

03

Transform passes

String pool encoding, symbol indirection, dead code injection, fake type paths, generic confusion, namespace virtualization.

04

Bytecode compiler

IR instructions compile into encrypted, remapped, build-specific opcode streams with 1-to-N opcode aliasing.

05

VM runtime generation

Polymorphic dispatch handlers, encrypted constant pool, optional rolling self-modifying bytecode.

06

Standalone bundle

CLI writes a clean, zero-dependency JS file to dist-obf/ — works in Node, browser, Electron, Workers.

Semantic-aware

Full TS Compiler API integration — understands types, imports, class hierarchies, and scopes.

1-to-N opcode aliasing

One instruction maps to many virtual opcodes, randomized per build. Defeats statistical pattern matching.

Anti-symbolic fake paths

Trap-backed unreachable blocks behind congruence predicates that waste dynamic exploration tools.

Rolling self-modifying code

Per-execution bytecode cloning with LCG-derived corruption masks and Shadow XOR Mask Buffer recovery.

Application profiles

Generic, React, Electron, Library — protection tuned to each deployment surface with framework-specific hardening.

WASM hybrid backend

Optional WebAssembly bootstrap validates native support while bytecode execution stays in the JS VM.

Security posture,
honestly stated.

No cryptographic claims. No silver bullets. Realistic protection levels against common threat profiles.

High

Naive static analysis

AST deobfuscators and signature regex tools lose the original execution shape entirely. Control flow, variable names, and literal values are gone.

Medium

Automated emulation

Rolling bytecode, opaque predicates, and indirect dispatch raise solver friction. Deterministic emulation can still trace behavior over time.

Low-Medium

Manual devirtualization

A skilled reverser with enough dynamic analysis time can recover behavior. Prioritize logic churn strategies when targeting advanced adversaries.
