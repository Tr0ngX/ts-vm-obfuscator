## Prompt Chính (Copy-paste thẳng vào AI)

```
Cinematic 9:16 vertical video, dark sci-fi tech aesthetic.
Left side: clean TypeScript code "function calculateHash(input: string): number" floating, syntax highlighted in white/blue.
The code slides into a glowing hexagonal compiler portal at center screen.
Inside the portal, the code breaks apart into particles and reorganizes.
Right side: pure encrypted bytecode hex stream "0x73 0xAE 0xF1 0x4D" flowing out in neon green.
The bytecode forms a rotating 3D hexagonal shield shape.
Below the shield, text "BYTECODE VM" in bold monospace neon cyan.
Lighting: volumetric cyan glow from the portal, dark background with subtle grid lines.
Camera: slow pan from left to right following the code transformation.
Atmosphere: floating hex numbers, digital particles, subtle scanlines.
Mood: technological marvel, secure transformation, confident.
No hands, no characters, no destruction.
--ar 9:16 --style raw
```

## Phân Tách Từng Yếu Tố

### 1. Composition & Camera

| Yếu tố | Chi tiết |
|---|---|
| **Frame** | 9:16 vertical (1080×1920) |
| **Shot type** | Wide establishing → Slow pan left to right |
