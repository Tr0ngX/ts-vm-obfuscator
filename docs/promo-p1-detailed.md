## ⚠ LƯU Ý: Prompt gốc bị reject vì nội dung bạo lực/hành vi phá hủy

## Phân Tách Từng Yếu Tố (để fine-tune)

### 1. Composition & Camera

| Yếu tố | Chi tiết |
|---|---|
| **Frame** | 9:16 vertical (1080×1920) |
| **Shot type** | Medium → Close-up push-in |
| **Camera movement** | Slow dolly zoom forward, micro-shake khi padlock vỡ |
| **Depth of field** | Shallow DOF, background mờ với floating particles |
| **Focus** | Sharp on the padlock, soft glow behind |

### 2. Lighting

| Light | Màu | Vị trí | Mục đích |
|---|---|---|---|
| **Key light** | Cyan #00e5ff | 45° trái trên | Chiếu sáng chính padlock |
| **Rim light** | Đỏ neon #ff0030 | 180° sau phải | Tạo viền đỏ nguy hiểm |
| **Fill light** | Xanh đậm #0a1628 | Phải dưới | Đổ đầy shadow không bị đen tuyệt đối |
| **Volumetric** | Cyan fog | Xuyên suốt scene | Tạo chiều sâu không gian |

### 3. Objects & Elements

| Element | Mô tả |
|---|---|
| **Padlock** | 3D, làm từ code symbols `{ } ( ) function var return if else`. Chất liệu giống digital wireframe nhưng đặc. Màu xanh cyan phát sáng. |
| **Bàn tay** | Găng tay đen với neon red trim. Chỉ thấy từ cổ tay vào, xuất hiện từ cạnh phải màn hình. |
| **Holographic screen** | Phía sau padlock, hơi mờ, chữ "DECOMPILED SUCCESSFULLY" màu đỏ |
| **Particles** | Floating hex numbers 0x00-0xFF, code fragments nhỏ, glow particles khi vỡ |
| **Scanlines** | Subtle CRT scanlines overlay xuyên suốt |

### 4. Time-based Animation (10s)

| Time | Event |
|---|---|
| **00 - 03s** | Establishing shot: Padlock floating, code symbols xoay chậm, camera push-in |
| **03 - 05s** | Tay xuất hiện từ phải, di chuyển chậm đến padlock |
| **05 - 07s** | Tay nắm padlock → snap vỡ (camera shake) |
| **07 - 08s** | Mảnh vỡ bay chậm, particles bung ra |
| **08 - 10s** | Text overlay xuất hiện với glitch effect, màn hình tối dần |

### 5. Text Overlay (Thêm sau trong editing)

| Nội dung | Font | Hiệu ứng | Vị trí |
|---|---|---|---|
| `AST OBFUSCATION = PLASTIC LOCK` | JetBrains Mono Bold | Glitch, chromatic aberration, flash | Center, 1.5s cuối |
| `TSXobf` (watermark nhỏ) | Inter Light | Opacity 30% | Góc dưới phải |
| `#1 / 7` | JetBrains Mono | Opacity 50% | Góc trên trái |

### 6. Âm Thanh (Add sau)

| Time | Sound |
|---|---|
| 00-03s | Low ambient hum, 40Hz sub-bass |
| 03-05s | Tiếng động cơ servo nhẹ (tay di chuyển) |
| 05-07s | *CRACK* — impact sound, glass breaking, reverb |
| 07-08s | Glitter/sparkle âm thanh mảnh vỡ rơi |
| 08-10s | Glitch điện tử + chữ xuất hiện |

### 7. Negative Prompt (Những thứ cần tránh)

```
bright, sunny, cartoon, realistic human face, real human hand (use stylized gloved hand), 
cluttered background, too much text, slow motion without impact, shaky without purpose, 
oversaturated colors, rainbow, anime style, low contrast, flat lighting
```

## Gợi ý Fallback

Nếu AI không tạo được chuyển động tay phức tạp, có thể chia làm 2 scene rồi ghép:

| Scene A (0-5s) | Scene B (5-10s) |
|---|---|
| Padlock floating, camera orbit | Padlock đã vỡ, mảnh bay, tay rút lui |
| Prompt: "3D code padlock floating, glowing cyan, dark void, cinematic push-in" | Prompt: "Shattered digital padlock pieces floating, code fragments dissolving, glitch text overlay" |

Ghép bằng CapCut: Scene A → cut đúng lúc → Scene B + sound effect.
