## Hướng Dẫn Cho AI Video Generator

### Tool:

| Tool | Cách dùng |
|---|---|
| **Runway / Pika / Kling / Sora** | Dùng cột "Visual" làm text-to-video prompt cho từng scene riêng. Output 14 clips. Ghép lại với narration và music. |
| **HeyGen / Synthesia / ElevenLabs** | Dùng narration text làm AI avatar voiceover. Scene visuals làm background overlay. Export MP4. |
| **CapCut / Premiere Pro / DaVinci** | Import từng scene clip riêng, ghép với narration track, thêm transitions và SFX. |

### Gợi ý visual style:

- **Color palette**: Đen (`#000000`), xanh dương đậm (`#0a0a2e`), cyan (`#00f0ff`), đỏ neon (`#ff0044`) cho cảnh báo
- **Font**: JetBrains Mono (code), Inter (text UI)
- **Hiệu ứng**: Glitch, scanlines, grid overlay, hex dump animation, terminal typing effect
- **3D elements**: Khối lục giác hexagon cho VM, dòng bytecode chảy (flowing hex stream)
- **Transition**: Glitch transition giữa các scene, fast cuts ở phần feature cards
